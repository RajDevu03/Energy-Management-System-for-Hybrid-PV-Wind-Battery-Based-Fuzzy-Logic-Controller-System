# Energy Management System for Hybrid PV-Wind-Battery Based Fuzzy Logic Controller System

## 📌 Overview

This project presents an **Energy Management System (EMS)** for a **Hybrid PV-Wind-Battery standalone renewable energy system** using a **Fuzzy Logic Controller (FLC)**. The system integrates **solar photovoltaic (PV)** energy, **wind energy**, and **battery storage** to ensure reliable and efficient power generation under varying environmental conditions.

The project was modeled and simulated using **MATLAB/Simulink** to optimize renewable energy utilization, improve system stability, and enhance operational efficiency.

---

## ⚡ Features

* Hybrid renewable energy integration:

  * Solar PV System
  * Wind Energy Conversion System (WECS)
  * Battery Energy Storage System (BESS)

* Intelligent Energy Management using:

  * Fuzzy Logic Controller (FLC)
  * MPPT (Maximum Power Point Tracking)

* Real-time energy balancing between:

  * Generation
  * Storage
  * Load demand

* Supports:

  * DC Loads
  * AC Loads through inverter

* Adaptive control under:

  * Variable solar irradiance
  * Variable wind speed
  * Load fluctuations

## 🧠 System Architecture

The hybrid system consists of:

1. **Solar PV Array**
2. **Wind Turbine Generator**
3. **Battery Storage System**
4. **DC Bus**
5. **Inverter**
6. **Fuzzy Logic Energy Management Controller**

The FLC continuously monitors:

* Solar irradiance
* Wind speed
* Battery State of Charge (SOC)
* Load demand

Based on these parameters, the controller decides:

* Battery charging/discharging
* Power sharing
* Load supply management

---

## 🔄 Working Principle

### Solar PV System

* Converts solar energy into electrical energy.
* MPPT extracts maximum available power.

### Wind Energy System

* Generates power based on wind speed variations.
* Complements PV generation during low sunlight conditions.

### Battery Storage

* Stores excess generated power.
* Supplies backup power during low renewable generation.

### Fuzzy Logic Controller

The FLC intelligently manages:

* Renewable power utilization
* Battery operation
* Load balancing
* System stability
